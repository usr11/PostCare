# Levantar el proyecto

## Linux
### Backend
```bash
cd backend 

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python run.py
```
### Frontend  
```bash
cd frontend

npm install 

npm run dev
```

## Windows
### Backend
```powershell
cd backend 

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python run.py
```
### Frontend  
```powershell
cd frontend

npm install 

npm run dev
```
